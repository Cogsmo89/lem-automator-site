# Lem Automator

Personal site for **Lemuel Duyag** — automation expert specializing in n8n, Make.com, Zapier, and GoHighLevel.

🌐 **Live:** [lemautomator.work](https://lemautomator.work) · [zingy-alfajores-e935d2.netlify.app](https://zingy-alfajores-e935d2.netlify.app/)

## Stack

- Static HTML / CSS / vanilla JS — no build step
- Hosted on **Netlify** (Netlify Forms for the contact form)
- DNS on **Cloudflare**
- Designed for SEO: JSON-LD `ProfessionalService` schema, Open Graph, sitemap, robots

## Local development

Just open `index.html` in a browser, or run a local server:

```bash
# Python
python -m http.server 8000

# Node
npx serve

# PHP
php -S localhost:8000
```

## Deploy

Drag the project folder onto [Netlify Deploys](https://app.netlify.com/) — it's a static site, no build needed.
